The real terminal app, captured from a test engine with made-up spaces. Truecolor terminals get these colours; others get your terminal's own sixteen.

Decide

One key per decision.

Home lists everything that needs you, longest waiting first, the same queue as the Mac app. Move with j and k, and the card you're on shows its keys.

  • a
    ApproveKeeps the result at the commit you saw. On a result that needs a look, the first press asks for a second.
  • s
    Send backWith a note. The writer carries on from its branch.
  • x
    StopStops a running task. It waits for a retry.
  • e
    Explain the problemOn a paused task: a read-only run says what's going wrong instead of trying again.
  • b
    Raise the budgetOn a budget pause: doubles what ran out and carries on.
  • A
    Approve all cleanEvery clean result at once.
  • 1-9
    AnswerA brief's questions, one number per listed answer.
  • ?
    Every keyThe full list for the tab you're on.

The dashboard adds z to take back the last approval and ⌘K for every action by name. The terminal app has neither: a yes there is final.

Run it

Install once. Then just type atrium.

You need a Mac with Apple silicon, bun, and the Claude Code CLI signed in. The engine runs in the background; the terminal app, the dashboard and the Mac app all talk to it.

zsh
$ git clone https://github.com/nakulpatel0306/atrium.git && cd atrium
$ bun install && bun link   # puts atrium on your PATH
$ atrium install           # starts Atrium now and at login
$ atrium
  • atriumThe terminal app.
  • atrium statusOne line: whether the engine runs, and how much needs you.
  • atrium --high-contrastQuiet text in your terminal's own colour, accents in bold.
  • NO_COLOR=1 atriumNo colour at all; selection stays readable.
  • atrium openThe same state in the browser.
Without leaving the terminal

The whole loop, from the keyboard.

  • spaceAsk for something new. It starts at once, from a brief.
  • n NA new task in this space, or a new space.
  • tRead the transcript of what the agent did.
  • y n NYes, not now or never to a suggestion; add a line to CLAUDE.md.
  • /Filter the list you're on.
  • uAgents and usage: Claude's five-hour window and what the agents cost.
  • AChange which agent takes a task.
  • oOvernight mode: keeps the Mac awake while work is queued.
